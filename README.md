# E-Commerce Sales Dashboard

An interactive E-Commerce Sales Dashboard built using Excel to analyze sales, profit, customers, products, payment methods, order status, shipping modes, and monthly sales trends.

## Project Overview

This project analyzes e-commerce sales data and converts raw transaction data into meaningful business insights using Excel.

The dashboard helps understand sales performance, customer behavior, product performance, order status, payment methods, shipping modes, and state-wise sales.
